# Application mobile Flutter

Ce dossier contient un premier prototype de l'application mobile côté client.

## Ce qui fonctionne dans ce prototype
- Affichage d'une liste de produits de démonstration
- Ajout et retrait d'articles du panier
- Calcul local du total
- Écran de confirmation de démonstration

**Important :** ce prototype n'est pas encore connecté au backend et ne transmet pas de commande réelle. Les produits sont des exemples enregistrés dans le code.

## Lancer l'application

Installer Flutter sur l'ordinateur, puis depuis ce dossier :

```bash
flutter pub get
flutter run
```

Pour lancer sur un téléphone, activer les options développeur et le débogage USB, puis brancher l'appareil. On peut aussi lancer un émulateur Android ou iOS.
